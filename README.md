# 花会替我说话

**Flowers Say What I Cannot.**

一座安静的数字花园——她打开时只看到一颗种子，每一朵花都是一句说不出口的话。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)

## 技术栈

- Next.js · TypeScript · Tailwind CSS
- Framer Motion（花朵绽放与章节转场）
- Canvas（草地、蝴蝶）
- Web Audio（轻环境氛围音）

## 体验路径

种子 → 遇见 → 喜欢 → 想念 → 温柔 → 秘密 → 花园苏醒 → 最后一朵 → 夜晚 → P.S. 彩蛋
